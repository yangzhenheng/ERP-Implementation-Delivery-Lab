# ERP 实施方案（演练版）

## 1. 项目目标
把“客户/订单/库存/工单”业务数据部署成可访问系统，并完成环境检查、数据初始化、接口联调、用户培训与验收。

## 2. 实施阶段
1. 需求调研：角色、流程、数据范围、接口、权限、交付边界。
2. 环境准备：操作系统、CPU/内存/磁盘、端口、防火墙、DNS、时间同步、账号权限。
3. 安装部署：Python venv、依赖、服务进程、Nginx 反向代理、健康检查。
4. 数据初始化：备份原数据，按模板清洗客户/订单/库存，先小批量验证再全量导入。
5. 联调测试：业务流程、接口、异常场景、权限、性能基础验证。
6. 客户培训：管理员与业务员分角色培训，形成签到、问题清单、操作手册。
7. 上线验收：关闭 P1、明确遗留项、备份/回滚方案、验收签字。

## 3. 验收口径
- `/health` 可用；关键接口返回正确。
- 导入前后数量/金额抽样一致。
- 关键流程可跑通。
- P1 问题为 0。
- 用户完成培训并可独立完成核心操作。
