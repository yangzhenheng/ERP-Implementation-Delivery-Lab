# 90 秒项目讲解

这是我针对 ERP/软件实施岗位做的个人实施交付演练项目，不把它包装成真实客户生产项目。

我把实施工作拆成需求调研、环境准备、安装部署、数据初始化、联调测试、客户培训和上线验收七个阶段。系统用 FastAPI 做服务层，SQLite 做零依赖演示数据库，同时准备了 MySQL 参考建表和 Oracle/SQL Server/DB2 方言差异速查。

演示时我会先打开驾驶舱，说明订单、库存、工单和实施任务；然后用 `/health` 证明服务和数据库可用，用 SQL JOIN/GROUP BY 做数据核对，再演示库存预警和工单。部署侧有 Linux 环境检查、systemd 服务和 Nginx 配置；交付侧有安装手册、数据迁移、故障排查、客户培训和验收清单。

我想证明的不是“我已经做过多年实施”，而是我理解实施工程师要把软件从安装、数据、联调一直交付到客户会用，并且问题能定位、过程有文档、结果可验收。
