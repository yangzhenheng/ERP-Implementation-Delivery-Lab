# 故障排查手册

## 客户说“系统打不开”
按链路排查，不先猜代码：
1. 客户端网络/IP/DNS。
2. 80/443 端口、防火墙、安全组。
3. Nginx 是否启动：`systemctl status nginx`。
4. 应用是否监听：`ss -lntp | grep 8000`。
5. 健康检查：`curl 127.0.0.1:8000/health`。
6. 日志：`journalctl -u erp-demo -n 100`。
7. 数据库可连接、磁盘空间、账号权限。

## SQL 查询慢
先看执行计划和索引；确认 WHERE/JOIN 字段是否有索引，避免无条件全表扫描和函数包裹索引列。

## 数据不一致
冻结继续导入 -> 定位批次 -> 对比源数据/目标数据 -> 找转换规则 -> 小范围修复 -> 复核 -> 记录原因与防再发措施。
