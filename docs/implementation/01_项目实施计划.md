# 项目实施计划

项目：Manufacturing ERP Implementation Delivery Lab

目标：演示制造业 ERP 从需求、环境、部署、数据、测试、培训到上线验收的实施闭环。

阶段：

1. 需求调研：确认客户、产品、仓库、库存、订单、问题和日志范围。
2. 环境检查：确认 Python、Docker、MySQL、Redis、Nginx、端口和磁盘。
3. 安装部署：本地 FastAPI 或 Docker Compose。
4. 数据迁移：CSV 清洗、测试导入、数量核对。
5. 接口测试：Swagger 和 pytest。
6. 培训：Dashboard、客户、产品、库存、订单、问题。
7. 上线演练：备份、启动服务、健康检查、业务验证。
8. 验收：按清单确认功能和边界。
