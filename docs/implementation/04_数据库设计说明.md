# 数据库设计说明

核心表：

- `customers`
- `products`
- `warehouses`
- `inventory`
- `sales_orders`
- `sales_order_items`
- `inventory_transactions`
- `implementation_tasks`
- `issues`
- `operation_logs`

设计原则：

- 主数据使用唯一编码。
- 订单头和订单明细分表。
- 库存按产品和仓库唯一。
- 库存变化写入流水，便于追溯。
- 问题记录根因和解决方案。
- 操作日志记录 request_id，便于排查。

MySQL 建表脚本见 `sql/01_schema.sql`。
