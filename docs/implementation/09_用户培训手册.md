# 用户培训手册

## 登录

本 Demo 未实现真实账号体系，直接访问 Dashboard。

## 客户管理

通过 Swagger `POST /api/customers` 新增客户，客户编码不能重复。

## 产品

通过 `GET /api/products` 查看产品编码、名称、分类、单位和标准价格。

## 库存

通过 `GET /api/inventory` 查看数量、安全库存和低库存状态。

## 订单

通过 `POST /api/orders` 新建订单。系统自动校验库存。

## 问题查询

通过 `GET /api/issues` 查看未关闭问题。

## Dashboard

查看订单数、今日订单、低库存、未关闭问题和实施进度。

## 退出

关闭浏览器页面即可。
