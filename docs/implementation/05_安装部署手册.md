# 安装部署手册

## 本地启动

```bash
python -m pip install -r requirements.txt
uvicorn app.main:app --reload
```

访问：

- `http://127.0.0.1:8000/`
- `http://127.0.0.1:8000/docs`
- `http://127.0.0.1:8000/health`

## Docker 启动

```bash
cp .env.example .env
docker compose up -d
docker compose ps
curl http://localhost/health
```

## 停止

```bash
docker compose down
```
