# 5 Minute Training Script

各位老师好，今天我给大家介绍这个 Manufacturing ERP 演示系统的基础使用流程。这个环境使用的是模拟数据，主要用于说明客户、产品、库存、订单和问题处理的操作方式。

首先打开系统首页 Dashboard。这里可以看到订单数量、今日订单、库存不足产品、未关闭问题和实施任务进度。如果业务人员反馈系统异常，我们会先看这里的系统状态，再结合日志排查。

第二步看客户管理。客户编码是后续订单和数据迁移的重要匹配字段，所以新增客户时必须确认编码、名称、联系人和电话。

第三步看产品和库存。产品有编码、名称、分类、单位和标准价格。库存按产品和仓库记录数量及安全库存。低于安全库存时，系统会显示低库存状态。

第四步看销售订单。新建订单时系统会校验库存。库存足够，订单可以确认并扣减库存，同时写入库存流水。库存不足，订单不会假装成功，而是生成问题记录，方便业务和实施人员跟进。

第五步看问题管理。每个问题要记录模块、严重级别、负责人、根因和解决方案。问题关闭前需要确认解决结果。

最后看实施任务和系统状态。实施任务用于跟踪需求、安装、配置、数据迁移、测试、培训、上线和验收。系统状态用于检查数据库、Redis 和应用是否正常。

今天的培训重点不是让大家记住技术细节，而是掌握日常业务操作和问题反馈路径：先确认业务数据，再记录问题，再由实施人员根据日志和数据库核对处理。
