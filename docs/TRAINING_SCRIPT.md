# 5 分钟用户培训话术

各位老师好，今天我介绍“制造业 ERP 实施交付实验室”的基础使用流程。当前环境使用模拟数据，主要演示客户、产品、库存、订单、问题和实施任务的业务闭环。

首先打开系统首页驾驶舱。这里可以看到订单总数、今日订单、销售金额、库存不足、未关闭问题、实施进度和系统状态。如果业务人员反馈系统异常，我们会先确认当前服务状态，再结合日志和数据库记录排查。

第二步是客户管理。客户编码是后续订单、数据迁移和对账的重要匹配字段。新增客户时必须确认编码、名称、联系人、电话和地址，避免后续订单无法关联。

第三步是产品和库存。产品包含编码、名称、分类、单位和标准价格。库存按产品和仓库记录数量及安全库存；当现有数量低于安全库存时，系统会标记低库存。

第四步是销售订单。新建订单时系统会自动校验库存。库存足够，订单可以确认并扣减库存，同时写入库存流水；库存不足，系统不会假装成功，而是生成问题记录，方便业务和实施人员跟进。

第五步是问题管理。每个问题要记录模块、严重级别、负责人、根因和解决方案。问题关闭前必须确认处理结果，避免上线后反复出现同类问题。

第六步是实施任务和系统状态。实施任务用于跟踪需求、安装、配置、数据迁移、测试、培训、上线和验收；系统状态用于检查数据库、Redis 和应用是否正常。

今天的培训重点不是让大家记住技术细节，而是掌握日常操作和问题反馈路径：先确认业务数据，再记录问题，再由实施人员根据日志、接口和数据库核对处理。
