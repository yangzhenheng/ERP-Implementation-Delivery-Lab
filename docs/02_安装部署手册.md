# 安装部署手册（Linux）

```bash
sudo mkdir -p /opt/erp-implementation-lab
cd /opt/erp-implementation-lab
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
curl http://127.0.0.1:8000/health
```

生产化演练使用 systemd：复制 `deploy/erp-demo.service` 到 `/etc/systemd/system/`，再执行：

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now erp-demo
sudo systemctl status erp-demo
journalctl -u erp-demo -n 100 --no-pager
```

若经 Nginx：检查 `proxy_pass`、防火墙、监听地址、SELinux（如适用）和上游服务状态。
